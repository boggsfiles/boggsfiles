# Script vs. Screen reports

For every future episode report, populate `drafts` with date, revision, format, status, and the matching script `url` from the episode’s existing scripts archive. Use `draft_rows` to link available revisions directly to their script viewer. Never invent a URL for a draft marked Not held; leave that revision as plain text.

User preferences: reports live as text on the site; no revision-report PDF files, PDF buttons, or Sources & Methodology section. Preserve the report findings and link available scripts in Draft History.
