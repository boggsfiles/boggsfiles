# X-Files location-scout archive

Scanned production memorabilia from the LA-era X-Files (seasons 6–9, 1998–2002).
Credit: Jeremy Royer / @unknownparish (Instagram). Scanned by Jeremy; folder labels
are the location department's handwriting on the manila folder tabs.

## Layout

```
NN-slug/
  LABEL.txt   exact handwritten folder label
  scans/      originals exactly as received (PDF / webp) — never edit
  full/       300 dpi JPEG, rotated upright, scanner bed trimmed (print quality)
  web/        same, 2000 px long edge, q85 (use these on the site)
tools/process.py   ingest script — see usage in the docstring
```

Add a new folder: `python3 tools/process.py NN-slug "Folder label" file1.pdf file2.pdf`

## What this collection is
**Provenance.** The scout folders were a single eBay purchase (seller: tjcanon). Asked where they came from, the seller told Jeremy: *"I got it from the person who did set location work for the show and many others."* (relayed 2026-09-24). The call sheets ("Unusual Suspects," "War of the Coprophages") are a separate acquisition from Don McGill and are **not** part of this lot.

That settles the shape of the collection: these are one location person's working files, spanning The X-Files **and other productions**. So the folders with no scene label, no frame match, or a date outside the show's LA years — Sierra Madre (tab dated 1/26/95), the backlot alley, the ranch-country landscapes — are not anomalies to explain away; they are the rest of that person's library, which came along with the X-Files material. The "library" tier on the site can be stated as fact, not inference.

Still open: the person's **name**, and which non-X-Files productions the other folders belong to. "Set location work" could mean location manager, scout, or assistant location manager. A name would let us check credits and attribute the collection properly.
